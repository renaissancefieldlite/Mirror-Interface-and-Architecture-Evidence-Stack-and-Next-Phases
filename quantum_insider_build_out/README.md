## Shared Visual RAG Layer

Add `Mirror Index Visual RAG` as the common backend for every track.

This is not a plain vector database. It is a Golden Field / Mirror Index memory
system:

```text
sponsor track
-> nest lane
-> enterprise state object
-> visual artifact / diagram / frame / graph
-> semantic + visual embedding
-> support-state label
-> control / drift / invariant tags
-> retrieval trace
-> proposal figure / PoC action
```

What it stores:

- screenshots, diagrams, protein pathway maps, grid graphs, VLA frames, flow
  fields, circuit diagrams, companion-map panels, and sponsor-specific proposal
  figures
- semantic nodes for claims, controls, invariants, drift modes, local engines,
  quantum forks, and benchmark gates
- support labels: `supported`, `partial_supported`, `protocol_ready`,
  `expansion_target`, `public_safe`, `private_ip`

What it does for Quantum Insider:

- turns five sponsor tracks into one navigable evidence system
- lets each proposal retrieve the exact diagram, benchmark, control, and next
  gate behind the claim
- gives the Lattice Model Node Companion a real visual-memory backend instead
  of becoming a static deck graphic
- creates a demoable product layer: ask a sponsor-track question, retrieve the
  relevant evidence card, visual node, local engine state, and quantum-enabled
  fork
