## Scope Boundary

This release is the self-contained public-safe full paper. It integrates the
origin in the Mirror Interface / LSPS interaction surface, measured AI state
paths, the Nest 1-5 program, formal systems, structured matter, solar
mechanics, biology, convergence, and the controlled return into AI.

The Lattice Companion remains the atlas. The Universal Data Pattern remains
the recurring cross-disciplinary state architecture. The UDP experiment is the
substrate-native test method. Typed evidence cards are the reporting and return
units.

Raw biometric exports, device identifiers, private capture paths, privately
parked architecture, runnable protected code, model states, and
claim-sensitive mechanics are excluded.
