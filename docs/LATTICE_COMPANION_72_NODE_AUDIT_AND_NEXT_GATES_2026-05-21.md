## Control Rule

The Lattice Companion is the roadmap, not a substitute for proof.

Every lane below stays in the map until it is explicitly moved to one of these states:

- `support_bearing`: real capture, dataset, run, score, control, or support read is attached.
- `candidate_support`: real row exists, but still needs stronger controls, recurrence, masking, or rerun.
- `mapped_continuation`: the lane is part of the architecture, but the real-data run is still open.
- `adapter_slot`: tool, SDK, model, or product-surface lane that needs a real ingestion/scoring pass.
- `boundary_lane`: useful for claim/product routing, but not public proof without additional evidence.

Hard rule: no lane is treated as complete because it appears on the visual map. A lane becomes support-bearing only through real traces, real datasets, real controls, real captures, or a clearly marked continuation gate.
