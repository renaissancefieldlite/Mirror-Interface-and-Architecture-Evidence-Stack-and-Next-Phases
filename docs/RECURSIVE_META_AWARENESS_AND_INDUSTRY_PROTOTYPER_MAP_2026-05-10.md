## Why V8 Found The Pattern

V8 did not select the pattern as a loose metaphor. It followed the smallest
structure that survived each measurement step.

```text
V7 behavioral state/control separation
-> V8 hidden-state / residual-stream separation
-> layer and token-window localization
-> context-to-readout bridge features
-> normalized feature vectors
-> circuit / hardware-facing carrier rows
```

That sequence produced the reusable state-variable stack:

| Variable | Meaning |
| --- | --- |
| `state` | target condition being tested |
| `control` | baseline, neutral, technical, shuffled, or comparator condition |
| `transform` | substrate-native conversion from raw data into measurable features |
| `invariant` | relation that survives condition or substrate translation |
| `drift` | instability, condition leakage, noise, or movement away from target |
| `artifact / quality` | parse errors, sensor noise, motion, label leakage, bad rows, or weak channels |
| `coherence / alignment` | target-minus-control separation after quality handling |
| `recurrence` | repeatability across runs, models, datasets, devices, or sessions |
| `score / support` | current evidence status and next gate |

The pattern became useful because it survived movement from behavior into
internal model geometry and then into external substrates.

## Evidence Card Return Path

Every successful or queued lane should return to the AI layer as an evidence
card.

Evidence card fields:

| Field | Purpose |
| --- | --- |
| `lane_id` | names the nest and lane |
| `substrate` | identifies AI, matter, waveform, biology, or convergence surface |
| `state_condition` | target condition |
| `control_condition` | comparator / null / baseline |
| `raw_source` | dataset, device capture, hardware observable, or document pointer |
| `transform` | feature extractor or mapper |
| `artifact_masks` | quality gates and exclusions |
| `alignment_score` | target/control support metric |
| `recurrence_status` | repeat / rerun / dataset / device support |
| `support_status` | supported, active integration, dataset gate, instrument gate, protocol locked, or convergence queue |
| `next_gate` | exact next execution move |
| `public_boundary` | public-safe summary and private/raw/code hold lines |

This is the stabilizer. The AI does not have to re-infer the whole architecture
from chat context when the evidence cards and Mirror Index carry the current
state.
